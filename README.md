# Abdu's Fintracker

A personal money tracker that installs on an iPhone home screen.

- Spending across several banks (PDF or CSV statement import, read on the phone)
- Subscriptions and debts, with due dates
- Weekly spending against a budget
- Savings goals with a monthly plan and a payday check-in
- Notifications (over budget now; payment, Sunday summary and payday reminders via the reminder server)

All money data is stored only on the phone. Nothing in this repo contains personal data.

Open https://aezedin.github.io/fintracker/ in Safari, then Share → Add to Home Screen.
